## 產生的 synthesis 洞察

在編譯過程中浮現三個值得保存的 cross-pattern 連結（已寫入 overview.md 與對應 pattern 檔案）：

1. **滑動窗口 × TCP 擁塞控制**：repo 內的 7 題滑動窗口都可延伸到 `kernel/network-sliding-window` 的雙層窗口（snd_wnd 流量控制 / snd_cwnd 擁塞控制）。面試可當加分話題。
2. **鏈表 × `list_head` 侵入式設計**：LeetCode 的 `struct ListNode` 是外部鏈表（節點內含 data + next）；kernel 的 `list_head` 是侵入式（把 list_head 嵌進 data struct）。前者教學清晰，後者真實系統必用（因一個節點可同時在多條鏈上）。
3. **二分搜尋的溢位處理**：LeetCode 704 的 `(lo + hi) / 2` 在極值會溢位，kernel `lib/bsearch.c` 用 `lo + (hi - lo) / 2`。這是 code review 常考點。
4. **Trie × `lib/xarray.c`（繼承自 radix-tree）**：Trie 的「把 key 切分段、每層索引一個 children 陣列」的思維，在 kernel 裡用於 page cache 索引。
